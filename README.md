# 飞书文档爬取工具 v22

将飞书知识库/文档一键导出为 Markdown 或 PDF，图片自动内嵌，代码块保留格式。

## 前置条件

**你至少需要对目标飞书知识库拥有「阅读」权限。** 工具使用你登录后的浏览器会话抓取页面，只能抓取你能正常打开的页面，不会绕过飞书的权限控制。

## 环境要求

- Python 3.9+
- Windows / macOS / Linux

## 安装

```bash
pip install playwright beautifulsoup4 lxml markdown
playwright install chromium
```

## 快速开始

**Windows**: 双击 `启动.bat`

**命令行**:
```bash
# 交互模式（菜单选择）
python feishu_crawler.py

# 快捷模式（直接传URL）
python feishu_crawler.py https://xxx.feishu.cn/wiki/ABC123

# 指定输出目录
python feishu_crawler.py https://xxx.feishu.cn/wiki/ABC123 ./我的文档
```

首次运行会弹出浏览器，登录飞书后自动记住，后续无需重复登录。

## 菜单说明

```
[1] 设置目标 URL     → 输入飞书知识库任意页面链接
[2] 设置导出目录     → 默认 ./feishu_output
[3] 导出格式设置     → Markdown（图片内嵌）/ PDF（合并单文件）
[4] 开始爬取         → 三阶段进度条，自动完成
[0] 退出
```

## 导出格式

### Markdown 模式（默认）
- 每个页面一个 `.md` 文件
- 图片以 base64 内嵌，单文件自包含
- 保留表格、链接、加粗、标题层级
- 代码块带语言标签（go/python/java 等）
- 自动删除空目录页

### PDF 模式
- 所有页面合并为一个 `.pdf` 文件
- 带目录导航、A4 排版、代码高亮
- 可选择是否保留原始 `.md` 文件

## 爬取流程

1. **发现页面** — 自动遍历飞书知识库导航树
2. **爬取内容** — 逐个页面抓取，进度条实时显示字数
3. **清理统计** — 删除目录页 → 智能排序 → 图片内嵌 → 输出报告

## 功能特性

| 功能 | 说明 |
|------|------|
| 智能代码块 | 自动检测缺失的代码块并补全 ``` 标记 |
| 图片内嵌 | base64 内嵌，.md 文件可单独迁移 |
| 章节排序 | 自动按课程结构排序（01-80） |
| 目录清理 | 自动删除飞书导航目录页 |
| 格式保护 | 表格、链接、标题、加粗完整保留 |

| 进度显示 | 三阶段进度条，实时显示文件名和字数 |
| 崩溃恢复 | 页面导航异常自动跳过，继续爬取 |
| 多知识库 | 同一浏览器登录态可爬任意飞书知识库 |

## 账号与隐私

- 登录信息保存在本地 `feishu_profile/` 目录，**不会上传到任何服务器**
- 如需切换飞书账号：菜单选 `[5] 清除登录状态`，下次爬取时重新扫码
- 公用电脑使用后建议执行清除，防止他人使用你的飞书账号
- 可将 `feishu_profile/` 加入 `.gitignore`，避免误提交到代码仓库

## 注意事项

- 爬取 99 页约需 50 分钟，取决于网络和页面数量
- PDF 模式文件较大（含图片），建议先用 Markdown 模式预览
- 图片较多时单个 .md 文件可能超过 50MB
- 飞书导航树每次展开状态可能略有不同，页面数可能 ±10
- 爬取过程中请勿关闭弹出的浏览器窗口
- 如需爬取不同知识库，建议使用不同的输出目录
- 首次登录后浏览器会记住登录态，勿在公共电脑上勾选"记住密码"
- 内嵌图片模式下 .md 文件较大，部分编辑器打开可能较慢

## 常见问题

**Q: 提示"需要登录"？**
浏览器弹出飞书登录页，扫码或输入密码即可。

**Q: 代码块格式不对？**
已自动修复。如果仍有个别页面代码块未识别，可提 issue 附带页面链接。

**Q: 图片显示不了？**
图片已 base64 内嵌到 .md 文件中，用支持 Markdown 的编辑器（VS Code、Typora、Obsidian）打开即可看到。

**Q: 能爬其他飞书知识库吗？**
可以，输入任意飞书知识库的页面链接即可。
